# Heal 24/7

Heal is a mobile-first React prototype for daily health and lifestyle check-ins. It helps users record what happened today, review a Health Score and Lifestyle Age, follow a routine, and ask Heal AI for context from their entries.

## Run locally

```bash
npm install
npm run dev
```

Create a production build with:

```bash
npm run build
```

This prototype is frontend-only. Daily data is held in the current browser session; no Django, wearable, Docker, or external API integration is required.
